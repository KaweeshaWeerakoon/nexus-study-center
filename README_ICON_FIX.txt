NEXUS APP ICON FIX

1. Upload index.html, manifest.json, nexus-192.png and nexus-512.png to the ROOT of your existing GitHub repository.
2. Replace the existing index.html when prompted. Keep the PNG files and manifest.json alongside index.html, not inside another folder.
3. Commit changes and wait for GitHub Pages deployment to finish.
4. Open the website in Microsoft Edge and press Ctrl+F5.
5. If the installed app still has the old icon: close NEXUS, open Edge > ... > Apps > Manage apps, uninstall NEXUS, then visit the site again and install it as an app.
6. Pin the newly installed app to Start/taskbar/desktop if needed. Windows may cache icons briefly.

Note: This adds a manifest and PNG icons. Edge/Windows may cache icons, so reinstalling may be needed.
