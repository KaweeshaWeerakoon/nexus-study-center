NEXUS — FUTURISTIC HTML EDITION
================================

NO PYTHON REQUIRED.

QUICK START
1. Extract the ZIP file to a folder you can find again.
2. Open the NEXUS_HTML_Futuristic folder.
3. Double-click index.html.
4. It opens in your browser (Microsoft Edge recommended).

This is a local, browser-based app. It has working navigation, timetable entries,
tasks, reminders, exam countdown, study-session logging, subject topic progress,
and JSON backup/import. Your data is stored in the browser's localStorage on this
computer. Do not clear browser data if you want to keep it. Export a backup in
Settings occasionally.

IMPORTANT LIMITATIONS
- Browser reminders are checked while the page is open; they are not guaranteed
  to alert when the browser is closed.
- The app works offline after the files have been extracted.
- Opening index.html is the simplest way to use it. To install it as a separate
  Windows app icon, it needs to be hosted as a secure website (HTTPS) or run
  through a small local web server; this ZIP by itself is the offline web app,
  not a signed Windows .exe installer.
- The schedule starts with example entries. Edit them to match your real week.
- The default exam date is 3 August 2027 and can be changed in Settings.
